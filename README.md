# Aurastic Productions

**An Artistic Execution Company**

Aurastic designs, plans, and delivers events as complete artistic experiences. We hold every event—a flashmob, a large-scale wedding, or a concert—to the highest standard of craft. The scale shifts, but the artistic commitment does not. 

Most companies sell equipment. Aurastic sells technical flow—the choreography that ties sound, light, LED, stage, and performance into the experience the client originally imagined.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** GSAP & Framer Motion
- **Deployment:** Vercel

## Local Development

To run the development server locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
